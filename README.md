# Netflix Style IPTV Application

A modern IPTV/OTT streaming application with Netflix-inspired UI, built with React, TypeScript, and Xtream Codes API integration.

## Features

- Authentication with Xtream Codes API
- Live TV streaming with EPG support
- Movies and Series catalogs with TMDB integration
- Modern video player with HLS.js
- Responsive Netflix-style UI with Tailwind CSS
- State management with Zustand
- Animations with Framer Motion

## Setup

1. Clone the repository
2. Install dependencies: `npm install`
3. Start development server: `npm run start`

## Usage

Enter your Xtream Codes server details (URL, username, password) on the login screen to access your content.

## Technologies

- React + TypeScript
- Zustand (State Management)
- Axios (API Requests)
- HLS.js (Video Streaming)
- Tailwind CSS (Styling)
- Framer Motion (Animations)
- React Router (Navigation)
